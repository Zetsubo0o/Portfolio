🚀 QUICK START (5 Minutes)

1. Import the hook and component:
   import { useTheme } from './hooks/useTheme';
   import ThemeSelector from './components/ThemeSelector';

2. Use in your component:
   function Settings() {
     const { switchTheme, currentTheme } = useTheme();
     return <ThemeSelector currentTheme={currentTheme} onThemeSelect={switchTheme} />;
   }

3. Done! Your theme system is active.

🔧 HOW IT WORKS

Theme Selection
  ↓
Hook Updates State
  ↓
CSS Variables Applied to DOM
  ↓
Fonts Load (if needed)
  ↓
Theme Saved to localStorage
  ↓
Page Re-renders with New Colors
  ↓
All Components Inherit New Theme
